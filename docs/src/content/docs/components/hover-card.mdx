Hover cards display supplementary content when the user hovers or focuses the trigger, without navigating away.

## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardPortal,
  HoverCardTrigger,
} from "shadcn-solid-components/components/hover-card"
```

## Exports

- `HoverCard`, `HoverCardPortal`, `HoverCardTrigger`, `HoverCardContent`
- Types: `HoverCardProps`, `HoverCardTriggerProps`, `HoverCardContentProps`
