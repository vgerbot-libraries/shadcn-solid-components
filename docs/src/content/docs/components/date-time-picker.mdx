`DateTimePicker` is a standalone datetime primitive built on Ark UI date-picker behavior, combining calendar selection with integrated hour and minute selectors in one panel. It supports both single and range datetime workflows and exposes an hour-cycle switch for 12h/24h display.

## Installation

```bash
pnpm add @ark-ui/solid
```

## Usage

```tsx
import { DateTimePicker } from "shadcn-solid-components/components/date-time-picker"
```

Use `selectionMode="range"` for range picking, `hourCycle={24}` for 24-hour display, and `minuteStep` to control minute option increments.

## Exports

- `DateTimePicker`
- Types: `DateTimePickerProps`, `DateTimePickerHourCycle`, `DateTimePickerPreset`, `DateRangePreset`

## API

### `DateTimePickerProps`

Extends Ark UI `DatePickerRootProps`.

Notable fields:

- `hourCycle` — `12 | 24`, controls 12h/24h display mode (`12` by default)
- `minuteStep` — minute option interval (`1` by default)
- `placeholder` — single-mode input placeholder override
- `rangeStartPlaceholder`, `rangeEndPlaceholder` — placeholders for range inputs
- `clearable` — shows clear trigger button
- `showMonthYearSelect` — enables month/year dropdowns in day view header
- `presets` — `{ label, value }[]` where `value` is `DateValue[]` or a `DateRangePreset` string key; rendered as a sidebar of quick-select buttons
- `showTodayButton` — shows a "Today" button below the calendar (`false` by default)
- `todayLabel` — label text for the today button (defaults to `"Today"`)
- `calendarHeader` — custom JSX rendered above the calendar views inside the content panel
- `calendarFooter` — custom JSX rendered below the calendar views inside the content panel
