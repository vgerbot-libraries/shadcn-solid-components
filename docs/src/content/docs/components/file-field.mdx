The file field composes a root control with optional dropzone, trigger, hidden input, and a list of selected files including preview, name, size, and delete actions.

## Usage

```tsx
import {
  FileField,
  FileFieldDropzone,
  FileFieldHiddenInput,
  FileFieldItem,
  FileFieldItemList,
  FileFieldTrigger,
} from "shadcn-solid-components/components/file-field"
```

## Exports

- `FileField`, `FileFieldHiddenInput`, `FileFieldDropzone`, `FileFieldTrigger`, `FileFieldItemList`, `FileFieldItem`, `FileFieldItemPreviewImage`, `FileFieldItemSize`, `FileFieldItemName`, `FileFieldItemDeleteTrigger`, `FileFieldLabel`, `FileFieldDescription`, `FileFieldErrorMessage`
- Types: `FileFieldProps` and matching `*Props` types for each part
