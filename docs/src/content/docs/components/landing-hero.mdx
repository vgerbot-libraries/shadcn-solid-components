`LandingHero` is a top-level header primitive for landing and marketing pages. It supports desktop navigation, optional nested menu items, primary and secondary action areas, and a responsive mobile drawer.

## Usage

```tsx
import { LandingHero } from "shadcn-solid-components/components/landing-hero"
```

## Exports

- `LandingHero`
- Types: `LandingHeroProps`, `LandingHeroBrandConfig`, `LandingHeroNavItem`, `LandingHeroNavChildItem`, `LandingHeroMobileBreakpoint`

## API

### `LandingHeroProps`

Extends `header` props (without `children`). Notable props:

- `brand` — required object with `title`, optional `logo`, optional `href`
- `navItems` — array of top-level items; each item can define `children`
- `primaryActions` / `secondaryActions` — custom action nodes
- `open`, `defaultOpen`, `onOpenChange` — controlled/uncontrolled mobile drawer state
- `closeOnSelect` — close mobile drawer after item click (default `true`)
- `mobileBreakpoint` — switch point for desktop vs mobile (`"lg" | "xl"`, default `"lg"`)
- `menuButtonLabel`, `menuPanelLabel` — accessibility labels for mobile menu controls
- `containerClass`, `brandClass`, `navClass`, `actionsClass`, `mobileMenuClass` — class overrides
