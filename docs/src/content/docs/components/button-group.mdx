`ButtonGroup` applies flex layout and border-radius rules so child buttons, selects, and inputs read as one control. `ButtonText` adds a muted label segment; `ButtonSeparator` adapts to the group orientation from context.

## Usage

```tsx
import { ButtonGroup, ButtonSeparator, ButtonText } from "shadcn-solid-components/components/button-group"
```

Set `orientation` to `"horizontal"` (default) or `"vertical"` on `ButtonGroup`.

## Exports

- `ButtonGroup`, `ButtonText`, `ButtonSeparator`, `buttonGroupVariants`
- Types: `ButtonGroupProps`, `ButtonTextProps`, `ButtonSeparatorProps`
