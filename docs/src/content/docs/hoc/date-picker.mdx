`DatePicker` in `shadcn-solid-components/hoc/date-picker` provides a pre-composed calendar input with day/month/year views, optional preset shortcuts, and single/range/multiple selection modes.

This HOC no longer handles field semantics such as `label`, `description`, or `error`; pair it with `FormField` when form UI and validation messaging are needed.

## Usage

```tsx
import { DatePicker } from "shadcn-solid-components/hoc/date-picker"
import { FormField } from "shadcn-solid-components/hoc/form-field"

<FormField label="Birthday" required>
  <DatePicker selectionMode="single" />
</FormField>
```

Root props such as `value`, `defaultValue`, `onValueChange`, `selectionMode`, `inline`, and locale-related options are forwarded to the underlying date-picker root.

Use `presets` with `DateRangePreset` keys (for example `last7Days`) to render quick range shortcuts.

## API

### `DatePickerProps`

Extends `div` props (minus `onChange`) plus a picked subset of Ark `DatePickerRootProps` (value, selection mode, views, locale, `inline`, etc.—see `src/hoc/date-picker/index.tsx` for the full picked list).

HOC-specific fields include:

- `placeholder`, `clearable`
- `presets` — `{ label, value }[]` where `value` is `DateValue[]` or a `DateRangePreset` string key
- `i18n` — partial locale for HOC strings
- `contentClass`, `showMonthYearSelect`, `showTodayButton`, `calendarHeader`, `calendarFooter`
- `required`, `invalid` — forwarded root state props for integration with external form wrappers

### `DatePickerPreset`

- `label`, `value` — `DateValue[]` or `DateRangePreset`

### `DateRangePreset`

String union such as `'thisWeek'`, `'last7Days'`, `'thisMonth'`, etc. (see source for the full set).
