`List` provides slot-based primitives for building advanced list UIs with consistent spacing, visual variants, and helper states. It stays presentation-focused so you can compose request logic, filters, and pagination outside the primitive layer.

## Usage

```tsx
import {
  List,
  ListBody,
  ListEmpty,
  ListHeader,
  ListItem,
  ListItemActions,
  ListItemDescription,
  ListItemMain,
  ListItemMedia,
  ListItemMeta,
  ListItemSubTitle,
  ListItemTitle,
  ListSkeleton,
  ListToolbar,
} from "shadcn-solid-components/components/list"
```

```tsx
<List variant="outlined" split itemLayout="horizontal">
  <ListBody>
    <ListItem selected>
      <ListItemMain>
        <ListItemTitle>Retail Intelligence Dashboard</ListItemTitle>
        <ListItemDescription>Operational analytics and conversion tracking.</ListItemDescription>
      </ListItemMain>
      <ListItemActions>...</ListItemActions>
    </ListItem>
  </ListBody>
</List>
```

Use `ListItem` props `selected` and `expanded` to apply state styles. Use `ListSkeleton` and `ListEmpty` for loading and empty states.

## API

### `ListProps`

Extends `div` props. Notable fields:

- `variant` — `'default' | 'outlined' | 'filled' | 'borderless'`
- `size` — `'sm' | 'default' | 'lg'`
- `split` — whether adjacent rows use dividing lines (default `true`)
- `itemLayout` — default row layout for child items: `'horizontal' | 'vertical'`

### `ListItemProps`

Extends `div` props. Notable fields:

- `layout` — per-item layout override (`horizontal` or `vertical`)
- `size` — per-item density override (`sm`, `default`, `lg`)
- `selected` — applies selected-row style
- `expanded` — applies expanded-row style

### Slot contract (for future `columns + listSlot` adapters)

- `ListItemTitle` → `title`
- `ListItemSubTitle` → `subTitle`
- `ListItemMedia` → `avatar`
- `ListItemDescription` → `description`
- `ListItemContent` → `content`
- `ListItemActions` → `actions`
- `ListItemAside` → `aside`
- `ListItemType` → `type`
