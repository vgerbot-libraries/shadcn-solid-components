`Item` provides a flexible row layout for content lists, settings rows, dropdown entries, contacts, notifications, and media lists. Compose media, content, and actions slots to keep spacing and alignment consistent across simple and interactive item UIs.

## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemGroup,
  ItemHeader,
  ItemMedia,
  ItemTitle,
} from "shadcn-solid-components/components/item"
```

Use `Item` as a standalone row or set `as="a"` for clickable link rows. Pair `ItemGroup` and `ItemHeader` when rows belong to a labeled section.

## Exports

- `Item`, `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemMedia`, `ItemActions`, `ItemGroup`, `ItemHeader`, `itemVariants`
- Types: `ItemProps`, `ItemContentProps`, `ItemTitleProps`, `ItemDescriptionProps`, `ItemMediaProps`, `ItemActionsProps`, `ItemGroupProps`, `ItemHeaderProps`, `ItemVariant`, `ItemSize`

## API

### `ItemProps`

Extends props for the rendered element. Notable fields:

- `as` — rendered element or component, such as `"div"` or `"a"`
- `variant` — `"default"` | `"outline"` | `"muted"` | `"destructive"`
- `size` — `"sm"` | `"default"` | `"lg"`
