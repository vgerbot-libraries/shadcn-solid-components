Mobile modules live under `shadcn-solid-components/mobile/<name>`. They may compose `components/` and `lib/`, and they may depend on other mobile modules.

On desktop and tablet, each Mobile page keeps a live phone preview on the right. On a phone viewport the preview column is omitted so the article stays readable.

Start with these modules:

- [Cascade](/docs/mobile/cascade) — stepwise picker for hierarchical options
- [Checkbox](/docs/mobile/checkbox) — circular checkbox and group
- [Picker](/docs/mobile/picker) — bottom-sheet wheel picker
- [Image picker](/docs/mobile/image-picker) — tile grid for selected images
- [Quantity stepper](/docs/mobile/stepper) — compact − value + control
