Chart support in this library centers on **composition**: you use `@unovis/solid` primitives for the actual series (areas, lines, bars, and so on), while `ChartContainer`, `ChartStyle`, `ChartCrosshair`, and `ChartTooltipContent` wire data, theming, and tooltips to your design tokens.

## Installation

Add the Unovis packages required by your chart types. They are optional peer dependencies.

```bash
npm install @unovis/solid @unovis/ts
```

Chart colors and tooltip chrome are intended to align with your CSS variables (for example chart color tokens defined in your theme).

## Usage

```tsx
import type { ChartConfig } from "shadcn-solid-components/components/chart"
import {
  ChartContainer,
  ChartCrosshair,
  ChartTooltipContent,
} from "shadcn-solid-components/components/chart"
import { VisArea, VisTooltip } from "@unovis/solid"
```

1. Define a `ChartConfig` object mapping series keys to labels, optional icons, and colors (including per-theme objects when needed).
2. Wrap your visualization in `ChartContainer`, passing `data`, a `type` such as `"xy"`, and `config`.
3. Use `ChartCrosshair` with a `template` that renders `ChartTooltipContent`, and add `VisTooltip` (or equivalent) as required by your Unovis setup.

Use `ChartStyle` when you need to inject chart-related CSS variables from configuration.

## Exports

- `ChartContainer`, `ChartStyle`, `ChartCrosshair`, `ChartTooltipContent`
- Types: `ChartConfig`, `ChartContainerProps`, `ChartStyleProps`, `ChartCrosshairProps`, `ChartTooltipContentProps`

For behavior and props of individual marks and scales, refer to the [Unovis documentation](https://unovis.dev/).
