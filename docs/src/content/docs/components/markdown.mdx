`Markdown` renders markdown content using `markdown-it` and supports a composable plugin system. The default package includes plugin factories for Mermaid, Vega, Vega-Lite, syntax highlight, copy actions, KaTeX, SMILES, table of contents, footnotes, emoji, task lists, annotations, containers, and sanitizer flows.

## Installation

```bash
pnpm add markdown-it markdown-it-highlightjs markdown-it-mermaid mermaid svg-pan-zoom vega vega-lite vega-embed markdown-it-katex katex markdown-it-smiles markdown-it-anchor markdown-it-table-of-contents markdown-it-footnote markdown-it-emoji markdown-it-task-lists markdown-it-deflist markdown-it-ins markdown-it-del markdown-it-mark markdown-it-container markdown-it-link-attributes markdown-it-collapsible markdown-it-sanitizer @traptitech/markdown-it-spoiler
```

## Usage

```tsx
import { Markdown } from "shadcn-solid-components/components/markdown"
import { createMarkdownHighlightPlugin } from "shadcn-solid-components/components/markdown/plugins/highlight"

const source = "```ts\nconsole.log('hello')\n```"

<Markdown value={source} plugins={[createMarkdownHighlightPlugin()]} />
```

Use `plugins` to control feature activation and order. Keep the base component minimal when only plain Markdown rendering is needed.

## API

### `MarkdownProps`

Extends `div` props.

- `value` — markdown string source
- `children` — fallback markdown string when `value` is undefined
- `plugins` — ordered plugin list
- `markdownItOptions` — forwarded options for `markdown-it`
- `allowHtml` — enables markdown HTML rendering (`false` by default)
- `sanitize` — optional post-render sanitizer
- `size` — typography scale (`sm | default | lg`)

## Notes

- Draw.io plugin is intentionally deferred and can be added later through the same plugin architecture.
- The KaTeX plugin injects KaTeX styles into the Markdown shadow root automatically.
- Plugins that require runtime styling inject styles into the Markdown shadow root instead of global CSS.
