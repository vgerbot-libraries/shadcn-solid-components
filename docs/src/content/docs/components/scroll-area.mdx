`ScrollArea` wraps Ark UI scroll-area primitives into a theme-friendly container with styled scrollbar parts. Use it to keep long content regions constrained while preserving accessible scroll behavior.

## Installation

```bash
pnpm add @ark-ui/solid
```

## Usage

```tsx
import { ScrollArea, ScrollAreaScrollbar } from "shadcn-solid-components/components/scroll-area"
```

```tsx
<ScrollArea class="h-72 w-56 rounded-md border">
  <div class="p-4">...</div>
  <ScrollAreaScrollbar orientation="horizontal" />
</ScrollArea>
```

Use the default vertical scrollbar from `ScrollArea` and append `ScrollAreaScrollbar` with `orientation="horizontal"` when the content also overflows on the x-axis.

## Exports

- `ScrollArea`, `ScrollAreaViewport`, `ScrollAreaScrollbar`, `ScrollAreaThumb`, `ScrollAreaCorner`
- Types: `ScrollAreaProps`, `ScrollAreaViewportProps`, `ScrollAreaScrollbarProps`, `ScrollAreaThumbProps`, `ScrollAreaCornerProps`
