`Textarea` provides a styled multiline text input with size variants, invalid-state visuals, and optional auto-resize behavior. Use `TextareaField`, `TextareaLabel`, and `TextareaDescription` to keep field composition aligned with other form controls, and add `TextareaCount` when you want character guidance.

## Usage

```tsx
import {
  Textarea,
  TextareaCount,
  TextareaDescription,
  TextareaField,
  TextareaLabel,
} from "shadcn-solid-components/components/textarea"
```

Set `autoResize` to grow with content and pair `maxLength` with `TextareaCount` for user feedback.

## Exports

- `Textarea`, `TextareaField`, `TextareaLabel`, `TextareaDescription`, `TextareaCount`, `textareaVariants`
- Types: `TextareaProps`, `TextareaFieldProps`, `TextareaLabelProps`, `TextareaDescriptionProps`, `TextareaCountProps`, `TextareaCountFormatter`
