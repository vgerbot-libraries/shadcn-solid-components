`Invoice` composes a production-ready invoice view for detail and print pages: issuer/customer blocks, invoice meta, itemized table, totals summary, payment details, notes/terms, and a print action.

## Usage

```tsx
import { Invoice } from "shadcn-solid-components/hoc/invoice"

<Invoice
  invoiceNumber="INV-2026-001"
  status="sent"
  paymentStatus="partial"
  issuer={{ name: "AdminLTE, Inc." }}
  customer={{ name: "Acme Corp" }}
  items={[{ quantity: 1, item: "Service", amount: 120 }]}
/>
```

When `onPrint` is provided, it runs first. Returning `false` prevents the default `window.print()` behavior.

## API

### `InvoiceProps`

Extends `div` props.

- `items` — `InvoiceLineItem[]` — invoice line items (required)
- `issuer`, `customer` — `InvoiceParty` — sender and recipient blocks
- `invoiceNumber`, `orderId`, `issueDate`, `dueDate`, `accountId` — invoice metadata fields
- `status` — `InvoiceStatus | string` — business status badge
- `paymentStatus` — `InvoicePaymentStatus | string` — payment status badge
- `paymentMethod`, `paymentReference`, `paidAt` — payment-related metadata
- `meta` — `InvoiceMetaItem[]` — extra key-value metadata rows
- `currency` — currency prefix symbol (default `"$"`)
- `totals` — `InvoiceTotals` — subtotal/tax/shipping/discount/total/paid/due overrides
- `paymentDetails`, `notes`, `terms` — extra content sections below line items
- `actions` — custom footer actions (rendered before print button)
- `showPrintButton` — boolean (default `true`)
- `onPrint` — `() => boolean | void` — called before default print; return `false` to skip `window.print()`
- `locale` — `Partial<InvoiceLocale>` — i18n overrides
