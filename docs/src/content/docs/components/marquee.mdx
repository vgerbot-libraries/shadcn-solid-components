`Marquee` repeats children into a continuous moving strip. Use it for partner logos, status tickers, or animated highlight rails in landing pages.

## Usage

```tsx
import { Marquee } from "shadcn-solid-components/components/marquee"
```

## Exports

- `Marquee`
- Type: `MarqueeProps`

## API

### `MarqueeProps`

Extends `div` props. Notable props:

- `reverse` — reverse animation direction
- `pauseOnHover` — pause animation when hovering the marquee group
- `vertical` — use vertical motion instead of horizontal
- `repeat` — number of repeated content blocks (minimum `1`, default `4`)

You can also tune speed and spacing via CSS custom properties in `class`:

- `--duration` (e.g. `"[--duration:24s]"`)
- `--gap` (e.g. `"[--gap:0.75rem]"`)
