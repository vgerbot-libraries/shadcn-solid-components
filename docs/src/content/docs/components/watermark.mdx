`Watermark` renders a repeated overlay across a container to mark sensitive content. Use it on dashboards, operation consoles, and internal reports where screenshot traceability is required.

## Usage

```tsx
import { Watermark } from "shadcn-solid-components/components/watermark"
```

Wrap the content you want to protect with `Watermark`. Configure `content` for text marks or `image` for a logo mark.

## API

### `WatermarkProps`

Extends `div` props. Notable props:

- `content` — watermark text, accepts a string or string array
- `image` — watermark image URL or data URL
- `width` / `height` — single watermark mark size in pixels
- `rotate` — watermark rotation angle in degrees
- `gap` — horizontal and vertical spacing between repeated marks
- `offset` — x/y start offset of the tiled pattern
- `zIndex` — overlay layer order inside the watermark container
- `font` — text style configuration for text watermark mode

### `WatermarkFont`

- `color` — text color (supports rgba for transparency)
- `fontSize` — text size in pixels
- `fontWeight` — text weight
- `fontFamily` — font family
- `fontStyle` — text style
- `lineHeight` — line height for multi-line content
