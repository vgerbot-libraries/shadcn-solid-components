`AppleDock` provides a container that tracks cursor position and magnifies nearby icons. Pair it with `AppleDockIcon` to build launchers, tool palettes, or floating action strips.

## Usage

```tsx
import { AppleDock, AppleDockIcon } from "shadcn-solid-components/components/apple-dock"
```

## Exports

- `AppleDock`, `AppleDockIcon`, `appleDockVariants`
- Types: `AppleDockProps`, `AppleDockIconProps`

## API

### `AppleDockProps`

Extends `div` props. Notable props:

- `direction` — vertical alignment of icons in the dock: `"top" | "middle" | "bottom"` (default `"middle"`)
- `iconSize` — base icon size in pixels (default `40`)
- `iconMagnification` — target icon size near the cursor (default `60`)
- `iconDistance` — interaction range around the cursor in pixels (default `140`)
- `disableMagnification` — disable proximity scaling while keeping dock layout

### `AppleDockIconProps`

Extends `div` props. Each icon can override dock-level values with `size`, `magnification`, `distance`, and `disableMagnification`.
