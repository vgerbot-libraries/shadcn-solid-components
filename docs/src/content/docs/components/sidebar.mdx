The sidebar system centers on `SidebarProvider` (state, cookie name, mobile breakpoint via `useIsMobile`) and `useSidebar()` for expand/collapse. `Sidebar` is the narrow or icon rail; `SidebarInset` is the main content column. Menu areas use composable pieces—`SidebarHeader`, `SidebarContent`, `SidebarFooter`, `SidebarGroup`, `SidebarMenu`, `SidebarMenuButton` (with `SidebarMenuButtonVariants`), actions, badges, skeleton placeholders, and nested `SidebarMenuSub*` items. A `SidebarRail` offers a hover target to expand when collapsed; `SidebarTrigger` toggles visibility.

On small viewports, the sidebar uses `Drawer` + `DrawerContent` for an off-canvas experience.

## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarHeader,
  SidebarInset,
  SidebarProvider,
  SidebarTrigger,
  useSidebar,
} from "shadcn-solid-components/components/sidebar"
```

Wrap the app (or shell) with `SidebarProvider`, render `Sidebar` beside `SidebarInset`, and place navigation inside `SidebarHeader` / `SidebarContent` / `SidebarFooter` using the `SidebarMenu*` building blocks.

## Exports

**Context:** `SidebarProvider`, `useSidebar`

**Layout:** `Sidebar`, `SidebarTrigger`, `SidebarRail`, `SidebarInset`, `SidebarHeader`, `SidebarFooter`, `SidebarSeparator`, `SidebarContent`

**Groups and menus:** `SidebarGroup`, `SidebarGroupLabel`, `SidebarGroupAction`, `SidebarGroupContent`, `SidebarMenu`, `SidebarMenuItem`, `SidebarMenuButton`, `SidebarMenuButtonVariants`, `SidebarMenuAction`, `SidebarMenuBadge`, `SidebarMenuSkeleton`, `SidebarMenuSub`, `SidebarMenuSubItem`, `SidebarMenuSubButton`

See `src/components/sidebar/index.tsx` for the full set of props types (for example `SidebarProviderProps`, `SidebarMenuButtonProps`, `SidebarMenuButtonOptions`).
