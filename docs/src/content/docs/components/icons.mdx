This entry point ships a large set of stroke-style SVG icons (for example `IconCheck`, `IconChevronDown`, `IconUser`). Each icon is a function component that renders an `<svg>` with `currentColor` strokes and accepts standard SVG element props such as `class` and `aria-hidden`.

## Usage

```tsx
import { IconCheck, IconChevronRight } from "shadcn-solid-components/components/icons"

// Use inside buttons, menus, or labels; size with utility classes on `class`.
```

## Exports

- Many `Icon*` named components (see `src/components/icons/index.tsx` for the full list). Props match `ComponentProps<'svg'>` (that alias is not exported from this entry).
