`StatusIndicator` renders a small semantic dot for online/offline/presence and in-progress states. Use `StatusDot` as an alias when you prefer a shorter name. Supported statuses are `online`, `away`, `busy`, `offline`, and `in-progress`.

## Usage

```tsx
import {
  StatusDot,
  StatusIndicator,
  statusIndicatorVariants,
} from "shadcn-solid-components/components/status-indicator"
```

```tsx
<StatusIndicator status="online" />
```

## Exports

- `StatusIndicator`, `StatusDot`, `statusIndicatorVariants`
- Types: `StatusIndicatorProps`
