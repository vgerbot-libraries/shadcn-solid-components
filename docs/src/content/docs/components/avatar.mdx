`Avatar` provides composable image/fallback slots for profile photos. Use `AvatarGroup` to stack multiple users and optionally show an overflow counter with `max` + `total`.

## Usage

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarGroup,
  AvatarImage,
} from "shadcn-solid-components/components/avatar"
```

```tsx
<Avatar src="https://github.com/shadcn.png">
  <AvatarImage alt="Shadcn" />
  <AvatarFallback>SC</AvatarFallback>
</Avatar>
```

## Exports

- `Avatar`, `AvatarImage`, `AvatarFallback`, `AvatarGroup`
- Types: `AvatarProps`, `AvatarImageProps`, `AvatarFallbackProps`, `AvatarGroupProps`
