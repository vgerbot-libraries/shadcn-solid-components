Cards provide structural slots—header, title, description, optional action area, content, and footer—for dashboards and settings panels.

## Usage

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "shadcn-solid-components/components/card"
```
