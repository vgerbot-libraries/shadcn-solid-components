Dropdown menus expose actions or navigation in a popover anchored to a trigger. The module follows Kobalte’s menu composition: trigger, content, items, separators, shortcuts, and nested submenus.

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuPortal,
  DropdownMenuTrigger,
} from "shadcn-solid-components/components/dropdown-menu"
```

## Exports

- `DropdownMenu`, `DropdownMenuPortal`, `DropdownMenuTrigger`, `DropdownMenuGroup`, `DropdownMenuSub`, `DropdownMenuRadioGroup`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`, `DropdownMenuContent`, `DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioItem`, `DropdownMenuGroupLabel`, `DropdownMenuItemLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`
- Corresponding `*Props` types for each component
