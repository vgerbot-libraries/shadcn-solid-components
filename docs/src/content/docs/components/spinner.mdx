`Spinner` renders a compact loading indicator with multiple built-in looks. Use `variant` and `speed` for common loading styles (including `cube-grid`, `fading-circle`, and `folding-cube`), or provide `icon` and `animationClass` to compose a custom spinner from the same generic base.

## Usage

```tsx
import { Spinner } from "shadcn-solid-components/components/spinner"
```

```tsx
<Spinner />
```

Use `class` to change visual size (for example `size-6`) and pass accessibility attributes when needed.

```tsx
<Spinner variant="bars" speed="fast" class="size-5 text-primary" />
```

```tsx
<Spinner
  animationClass="animate-bounce"
  icon={<svg viewBox="0 0 24 24" fill="currentColor">...</svg>}
/>
```

## Exports

- `Spinner`, `spinnerVariants`
- Types: `SpinnerProps`, `SpinnerVariant`, `SpinnerSpeed`
