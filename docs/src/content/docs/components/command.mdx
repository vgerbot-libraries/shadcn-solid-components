Command provides a styled `cmdk-solid` surface: root, dialog variant, input, list, empty state, groups, items, separator, and shortcut text.

## Installation

```bash
pnpm add cmdk-solid
```

## Usage

```tsx
import {
  Command,
  CommandDialog,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
  CommandShortcut,
} from "shadcn-solid-components/components/command"
```

`CommandDialog` accepts optional `title` and `description` alongside the underlying dialog props from `cmdk-solid`.

## Exports

- `Command`, `CommandDialog`, `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup`, `CommandSeparator`, `CommandItem`, `CommandShortcut`
- Types: `CommandProps`, `CommandDialogProps`, `CommandInputProps`, `CommandListProps`, `CommandEmptyProps`, `CommandGroupProps`, `CommandSeparatorProps`, `CommandItemProps`, `CommandShortcutProps`
